# State Parks

A searchable, sortable table of **every individual park in all 50 state park systems** — 3,520 parks, forests, historic sites, recreation areas, beaches, and trails, each linked to its page on the state agency's own website.

- **[View the table](https://tim-army.github.io/State-Parks/)** — search across all 50 states, filter to one state, sort any column.
- **[`parks.csv`](parks.csv)** — `State`, `Park Name`, `County`, `Official Website` (one row per park). Counties come from Wikidata and OpenStreetMap, located to a county through the FCC's Census area API, with hand-checked overrides in [`scrape/county-overrides.csv`](scrape/county-overrides.csv); see [`scrape/counties.py`](scrape/counties.py). Parks spanning several counties list them comma-separated where the source gives them; point-based matches give the county at the park's mapped point. 114 small units (mostly Alaska recreation sites and trail segments) have no county yet.
- **[`state-park-systems.csv`](state-park-systems.csv)** — one row per state: the park system and its main website.
- **[`index.html`](index.html)** — self-contained page; data is embedded, no dependencies. Three tabs: all parks, **Will my rig fit?**, and RV rules by state. Generated by [`build_site.py`](build_site.py) from [`site-template.html`](site-template.html) and the CSVs.

## How the data was collected

Each state was scraped from its own park agency's website — sitemaps where they existed,
park-finder listings and JSON APIs otherwise. Park names come from the state's own page
titles or listing text, not from a third-party source. The scrapers live in
[`scrape/`](scrape/): [`lib.py`](scrape/lib.py) holds the shared helpers,
[`titles.sh`](scrape/titles.sh) fetches page titles in parallel, and
[`scrape/out/`](scrape/out/) keeps one CSV per state.

Every URL was requested live. 2,952 returned `200`; the remaining 605 return `403` to
command-line clients (New York, Florida, Massachusetts, Nebraska, Louisiana, and Kansas all
sit behind bot protection) and were verified through a real browser instead. Three dead
Texas URLs were dropped.

Counts reflect what each agency lists today, so a few states include units beyond
"state park" proper — Maine's public lands, New Jersey's state forests and marinas,
Massachusetts's reservations, Wisconsin's state trails — because the agencies list them
alongside their parks.

## RV and tow-vehicle rules

- **Will my rig fit?** — the [live page](https://tim-army.github.io/State-Parks/#fit) takes your RV or trailer length and your tow vehicle, and lists every campground with a site long enough, filterable by hookups (electric / water + electric / full), 30 or 50 amp service, pull-through, state, and state parks vs. federal campgrounds.
- **[`rv-policies.csv`](rv-policies.csv)** — one row per state: published length limit, measured average and longest site, whether the tow vehicle counts, vehicles per site, where extras park, and a source URL.
- **[`rv/site-combos.csv`](rv/site-combos.csv)** — every RV-capable state-park campsite, grouped by park, length, hookups, amps and driveway type.
- **[`campsite-rv-lengths.csv`](campsite-rv-lengths.csv)** / **[`campsite-rv-summary.csv`](campsite-rv-summary.csv)** — per park and per state rollups: site count, shortest, longest, average, median, size bands, electric / full-hookup / pull-through counts.
- **[`federal/federal-combos.csv`](federal/federal-combos.csv)** / **[`federal-rv-summary.csv`](federal-rv-summary.csv)** — the same for federal campgrounds (Park Service, Forest Service, Army Corps of Engineers, BLM, Bureau of Reclamation) from Recreation.gov.
- **[`rv/checkin-times.csv`](rv/checkin-times.csv)** — each state's standard campsite check-in and check-out time with its official source (also in `rv-policies.csv` and the policy table). Federal campgrounds carry their own times from Recreation.gov ([`federal/federal-times.csv`](federal/federal-times.csv)); both show in the fit tool's Check-in / Check-out columns.
- **[`virginia-rv-site-sizes.csv`](virginia-rv-site-sizes.csv)** — Virginia's own published per-park breakdown.

### How the measurement works

Every state-park figure comes from the state's own reservation system, one scraper per platform. The browser-based
ones live in [`rv/browser/`](rv/browser/) and run inside a tab on the booking site; the plain-HTTP ones are Python.

| Platform | States | Where the length lives |
|---|---|---|
| US eDirect / Tyler | CA, FL, OH, AZ, NV, VA, IL, MO, ND, MN, WY | `search/grid` → `VehicleLength` per unit ([`usedirect.js`](rv/browser/usedirect.js)); Wyoming only in the per-unit `search/details` "Unit & Parking Size" ([`wyoming.js`](rv/browser/wyoming.js)) |
| ReserveAmerica / Aspira `.do` | NY, TX, GA, OR, IA, UT, NE, NM, NC, MT, DE, MD, KY, IN, PA, OK, CT, NH, RI, MA, AK, VT | "Equip length / Driveway" column of `campsitePaging.do`, with hookup icons ([`reserveamerica.js`](rv/browser/reserveamerica.js)) |
| Camis / GoingToCamp | WA, WI, MI | tenant-specific attribute in `/api/resourcelocation/resources` ([`goingtocamp.js`](rv/browser/goingtocamp.js)) |
| Itinio | TN, SC, AR | `data-maxrv` on every site in the park-wide calendar POST ([`scrape_itinio.py`](rv/scrape_itinio.py)) |
| Brandt | SD, LA | `MaxEquipLength` in the page's embedded `var sites` JSON ([`scrape_brandt.py`](rv/scrape_brandt.py)) |
| Aspira `.page` | CO | "Maximum Vehicle Length" in the campground map's GIS feed ([`aspira.js`](rv/browser/aspira.js)) |

Each scraper emits a compact per-park aggregate (`rv/sites/<state>.txt`) with a checksum; [`rv/build_sites.py`](rv/build_sites.py)
turns those into hookup classes and driveway types, and [`build_site.py`](build_site.py) rebuilds the page, CSVs and the
tables in this README. Traps worth knowing: the ReserveAmerica pager repeats its last page instead of ending (dedupe by
site ID); an ADA icon inside the max-people cell breaks naive column parsing; Ohio sells marina docks through the same
endpoint as campsites; GoingToCamp attribute IDs differ per tenant; Colorado's map feed 500s unless the campground details
page is loaded first; Illinois labels sites by class (AA = full hookup, A and B/E = electric, B/S and C = none); and
Chrome throttles timers in background tabs, so the browser scrapers sleep on a Web Worker clock.

### What the states themselves publish

**No state publishes a system-wide maximum RV length.** The limit is set per campsite and lives in the reservation
system — which is exactly why the measured tables exist. Statewide pages give vehicle *counts*, not lengths.

**Does the tow vehicle count?** Four states answer plainly, and all four say yes:

| State | Wording |
|---|---|
| Oregon | "you must also be able to fit your tow vehicle onto the paved driveway" — a 25 ft RV behind a 22 ft vehicle needs a 47 ft site |
| Wisconsin | the listed length "indicates the maximum driveway length you have to fit all your equipment on the site (your trailer or RV, including the tow vehicle)" |
| Arkansas | "combined length … may not exceed the capacity of the camping spur" |
| Missouri | "All wheeled equipment/vehicles must fit on the parking pad/area" |

Wyoming's own field definition agrees: "Total Vehicle and Equipment available parking in feet." Florida gets there
indirectly ("consider the overall length and width of your camper or RV **and your tow vehicle**"), and Utah counts them
as one unit for vehicle limits. Everywhere else it is unstated — so assume the whole rig has to fit, which is why the fit
tool counts the tow vehicle by default.

**Where the tow vehicle parks** varies: Ohio sends extras to the camp office lot, Pennsylvania to a second-car lot or
onto the spur for a fee, Indiana to designated campground lots, Oregon and Texas to overflow areas. Colorado issues a
free towed-vehicle pass; Arizona waives the extra-vehicle fee for a towed car; Rhode Island's single vehicle pass covers
either the motorhome or the vehicle towing the trailer.

### Limits

Policy rows are sourced from each state agency's own camping rules in September 2026, and every row cites its page.
"Not stated" means the state does not publish that fact, not that no limit exists.

States without measured state-park data, and why:

- **Alabama** — Itinio like Tennessee, but its bot protection escalated to a human-verification challenge partway through; not bypassed.
- **Idaho** — Itinio behind an AWS WAF CAPTCHA.
- **Kansas** — the length appears only on each site's individual detail page, not in any list or map feed.
- **Mississippi** — GoingToCamp, but no length attribute is published at all.
- **New Jersey** — its own system publishes no per-site length.
- **West Virginia** — publishes only size buckets ("30' to 40' RV"), and only for sites available on the dates searched.
- **Maine** — length is free text on individual site pages, and its online season had closed.
- **Hawaii** — no RV camping in the state park system.

Federal campgrounds cover most of these states in the fit tool. Some systems leave out a whole field: Florida,
Louisiana and Vermont publish no per-site hookups, North Dakota's site types (Standard / Modern / Premium) aren't defined
anywhere it publishes, and most US eDirect states publish no driveway type. Louisiana marks most sites "999" (no limit
set), so only its sites with a real number are counted. Alaska lists a length on very few sites.

## Updating

Two GitHub Actions workflows keep the data current:

- **[Refresh federal campgrounds](.github/workflows/refresh-federal.yml)** — monthly: downloads the RIDB export, runs
  `federal/build_ridb.py` and `build_site.py`, and commits if anything changed.
- **[Refresh state-park campsites](.github/workflows/refresh-states.yml)** — quarterly, or on demand for chosen states:
  runs the browser scrapers headless through [`rv/refresh_states.mjs`](rv/refresh_states.mjs) (Playwright + Chromium)
  and the Python scrapers, then rebuilds. A state that fails keeps its previous numbers.

By hand: `node rv/refresh_states.mjs ny tx`, `python3 rv/scrape_itinio.py tn`, then
`python3 rv/build_sites.py && python3 build_site.py`. To refresh the park directory itself, re-run a state's scraper in
`scrape/` and rebuild `parks.csv`.
